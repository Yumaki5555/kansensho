# 世界の感染症と日本の水際対策

HIV/エイズ・梅毒・はしか・結核について、①どの国でどの感染症が多いか（WHO）、②日本がどの国と外国人材の協力覚書を結んでいるか、③日本への入国前にどんな検査・健康診断の制度があるか、④国内でどの程度の患者が出ているか、⑤治療にいくらかかり、税金・公的医療保険・本人がどう負担するか、を公的資料だけで比べられるページです（2026年10月26日に「日本の感染症を知る」から全面改修）。
国内の数字と制度は国の公式資料（厚生労働省・国立健康危機管理研究機構・出入国在留管理庁・外国人技能実習機構・e-Gov法令検索など、一部は自治体）、国別の数字と世界の動向は国連の機関（WHO・UNAIDS・IOM・国連統計部）の公式資料です。

- 公開先：https://yumaki5555.github.io/kansensho/ （リポジトリ：Yumaki5555/kansensho、main ブランチの `docs` フォルダを公開）
- 入口サイト「日本を知る。」の「調べる・比較する」に掲載
- 作成日：2026年10月26日（この日までに国が公表した資料をもとにしています）

## フォルダの役割

| 場所 | 役割 |
|---|---|
| `docs/` | **公開されるページ**（index.html、data.js、Excel、サムネイル、アイコン） |
| `data/research/` | 病気ごとに調べた結果（数字・出典URL・注意点）。ここが元データ。`world_hiv.json` はHIV/エイズの世界の動向、`kouhi.json` は公費で受けられる支援（検査・予防・治療。比較表の目安は「公費制度あり／条件付きで公費制度あり／対象となる公費制度を確認できず」の3つ）。2026-10-26に追加：`world_stats.json`（国別の数字。`build/fetch_world_stats.py` がWHOから自動で作る）、`seido.json`（協力覚書40本と入国前・入国時の健康確認の制度。状態は「実施中／開始予定／制度対象外／検査制度なし／未確認」）、`costs.json`（治療費と公的負担。確認できない値は null と「公表値を確認できず」）、`disease_info.json`（4つの病気の概要・感染経路・世界の状況・検査・予防・治療）、`others_guide.json`（その他の感染症9つと「さらに詳しく調べたい方へ」の資料31件） |
| `data/out/` | 元データを、Excelとページ共通の形にまとめたもの |
| `build/page_fragment.html` | ページ本体（グラフ・表・文章の作り）。claude.ai 版のページと共通の作り（`dash` という小さな仕組みでデータを受け取る） |
| `build/fetch_world_stats.py` | WHO（結核の推計・はしかの報告数・HIV〔UNAIDSの推計〕・梅毒の報告）と国連のM49（地域）を取ってきて `data/research/world_stats.json` を作る。ダウンロードは `build/_dl`（GitHubには送らない）。新しく取り直すときは `--refresh` |

| `build/build_xlsx.py` | `data/out` → Excel を作る |
| `build/excel_recalc.ps1` | Excel で数式を計算し、エラーがないか確かめて保存する |
| `build/build_site.py` | `data/out` とページ本体 → `docs/` を作る |
| `ogp/ogp.html` | サムネイル（docs/ogp.png）の元 |

## ページの作り（2026年10月26日の全面改修後）

- トップ：題名「世界の感染症と日本の水際対策」、4つの大きな入口（国別に比較する／4つの感染症を見る／日本の入国前対策を見る／国内の状況・公費を見る）、その下に「国別感染状況 × 日本との協力覚書 × 入国前検査」の表
- 上の追従メニューは5つ：国別に比較（#countries・#world）／4つの感染症（#diseases と #hiv など）／入国前対策（#entry）／国内の状況・公費（#compare・#kouhi・#cost）／資料・注意事項（#guide・#sources・#links）。分類の中は2段目のメニューで切りかえる
- 国別の比較（#countries）：216の国・地域。最初は「日本と関係の深い国」（協力覚書の20か国＋JPETSの対象国＋参考の日本）。病気の切りかえ・地域・協力覚書・入国前検査での絞り込み・国名検索・並び替え・8か国までの比較。国名を押すと下に A感染症の状況／B協力覚書／C入国前の健康確認／D制度上の確認事項。`#c-PHL` のようにISO3コードで国の詳しい情報へ直接行ける
- 病気のページはどれも同じ9つの節：1概要 2感染経路 3世界の感染状況 4国別比較 5日本国内の推移（これまでの図表すべて）6検査・予防・治療 7入国前対策 8医療費・公費負担 9出典・注意事項
- 最新の確定値と最初の年（HIV/エイズ・結核2016年、梅毒・はしか2015年）の比は「基準年比」（収録開始年比）と呼ぶ。間は9年なので「10年前比」とは書かない（2026-10-27の監査で修正）
- 梅毒の男女別には「性別不明」の行がある（年ごとの表とふれたときの説明に出す。積み上げ棒では合計−男性−女性を灰色で示す）
- はしかの「人口100万人あたり」は、はしかの報告の年（2025年）の数を、WHO結核推計の人口（2024年）で割った暫定の目安。画面に人口の年を出している
- グラフは棒グラフが基本（年ごとの推移は縦棒、国別・医療費は横棒、払い手の内訳は100%積み上げ）。必要なところだけ「折れ線」に切りかえられる。速報値は斜線・点線の枠・「速報」の文字。値のない年・国は「データなし」と書き、0にしない。ふれる（スマートフォンはタップ）と人数・率・前年との差・数字の種類・出典が出る
- 治療費と公的負担（#cost）：払い手のちがい、国民医療費の財源、払い手の割合（制度のきまりからの試算）、HIVの1年間の医療費（研究）、抗HIV薬の薬価、病気ごとの費用の表、医療費の内訳の試算（70歳未満のみ。高額療養費は令和8年8月〜令和9年7月の額。2026-10-27に「多数回該当」の選択と、同じ医療費が1年間〔8月〜翌年7月〕続いた場合の目安〔多数回該当・年間上限の払い戻し〕を追加。年間上限は「健康保険だけ」のときだけ計算し、公費の制度と一緒に使うときは扱いが国の資料で確認できないため入れない。令和9年8月からは所得区分が13に分かれるので、`page_fragment.html` の `KOGAKU` を直す）
- どのページでも下に「本サイトのご利用にあたって」（6項目）。検索（右上、または「/」キー）は国名（表に出ていない国も）・見出し・表・出典から探せる
- グラフの「画像で保存（PNG）」：1920×1080（16:9）で、タイトル・対象年・単位・出典を入れて保存する
- 掲載内容の日付（2026年10月26日時点）は `build/build_site.py` の `AS_OF` と、`page_fragment.html` のトップ・フッターの文にある。数字を新しくしたら一緒に直す
- claude.ai のダッシュボード版は、新しいデータ（countries・entry・costs・info・others・guide）がなくても、その部分だけ空で表示される作り

## 数字を新しくするとき

1. `data/research/` の該当する病気のファイルを、国の新しい資料で直す（出典URL・公表日も）
   - 世界の動向（`world_hiv.json`）：UNAIDSの推計は毎年7月ごろに新しくなる。AIDSinfo（https://aidsinfo.unaids.org/）の「Factsheets」で世界・地域・各国を選んで数字を読み取る。協力覚書の国は出入国在留管理庁（特定技能・育成就労）と外国人技能実習機構（技能実習）の一覧で、入国前結核スクリーニングは厚生労働省のページで確かめる
2. 感染症フォルダで次を順に実行する（国別の数字を新しくするときは、最初に `python -I build/fetch_world_stats.py --refresh`）

```
python -I build/consolidate.py data/research data/out
python -I build/build_xlsx.py data/out 日本の感染症の状況_2026年10月.xlsx
powershell -File build/excel_recalc.ps1 -Path "（Excelの場所）"
python -I build/build_site.py
```

3. `docs/` の変更を GitHub に送る（数分で公開ページに反映されます）
