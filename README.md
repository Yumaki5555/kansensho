# 世界の感染症と日本の水際対策

HIV/エイズ・梅毒・はしか・結核について、①どの国でどの感染症が多いか（WHO）、②日本がどの国と外国人材の協力覚書を結んでいるか、③日本への入国前にどんな検査・健康診断の制度があるか、④国内でどの程度の患者が出ているか、⑤治療にいくらかかり、税金・公的医療保険・本人がどう負担するか、を公的資料だけで比べられるページです（2026年10月26日に「日本の感染症を知る」から全面改修）。
国内の数字と制度は国の公式資料（厚生労働省・国立健康危機管理研究機構・出入国在留管理庁・外国人技能実習機構・e-Gov法令検索など、一部は自治体）、国別の数字と世界の動向は国連の機関（WHO・UNAIDS・IOM・国連統計部）の公式資料です。

- 公開先：https://yumaki5555.github.io/kansensho/ （リポジトリ：Yumaki5555/kansensho、main ブランチの `docs` フォルダを公開）
- 入口サイト「日本を知る。」の「調べる・比較する」に掲載
- 作成日：2026年10月26日（この日までに国が公表した資料をもとにしています）

- claude.ai のダッシュボード版は、新しいデータ（countries・entry・costs・info・others・guide）がなくても、その部分だけ空で表示される作り

## 数字を新しくするとき

1. `data/research/` の該当する病気のファイルを、国の新しい資料で直す（出典URL・公表日も）
   - 世界の動向（`world_hiv.json`）：UNAIDSの推計は毎年7月ごろに新しくなる。AIDSinfo（https://aidsinfo.unaids.org/）の「Factsheets」で世界・地域・協力覚書の国を選んで数字を読み取る（2010年比はファクトシートにしかない）。そのほかの国は `build/fetch_unaids_estimates.py` の資料のURL（UNAIDSの「HIV estimates with uncertainty bounds 1990-（年）」のページにある表計算ファイル）を新しい年のものに直して `--refresh` で取り直す。`consolidate.py` は、協力覚書の国について、ファクトシートの値と全部の国のファイルの値が同じかを確かめる（違うと止まる）。協力覚書の国は出入国在留管理庁（特定技能・育成就労）と外国人技能実習機構（技能実習）の一覧で、入国前結核スクリーニングは厚生労働省のページで確かめる
   - 都道府県の覚書（`seido.json` の `moc_pref`）：元は「労働関係」フォルダの mou-map（日本と世界のMOUマップ）の `data/mous/pref-*.json`。そのうち分野に `labor` があり、予定だけ・報道だけ・終了・期間切れでないもので、県（府・道）の公式ページで確かめられるものだけを入れる。相手・分野・内容の文は、報道（JETRO・現地紙など）にしかない内容を入れずに短く書き直している。選び方と除いたものは `検証記録/2026-10-28_都道府県の覚書.md`
2. 感染症フォルダで次を順に実行する（国別の数字を新しくするときは、最初に `python -I build/fetch_world_stats.py --refresh`）

```
python -I build/consolidate.py data/research data/out
python -I build/build_xlsx.py data/out 日本の感染症の状況_2026年10月.xlsx
powershell -File build/excel_recalc.ps1 -Path "（Excelの場所）"
python -I build/build_site.py
```

3. `docs/` の変更を GitHub に送る（数分で公開ページに反映されます）
